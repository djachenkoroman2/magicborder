Задача: добавить в свойства изображения вычисляемую площадь контура в квадратных миллиметрах.

Контекст:
- В приложении уже есть панель "Свойства изображения".
- В группе "Информация о контуре" уже отображаются вычисляемые свойства, например количество пикселов контура.
- В приложении также есть калибровка масштаба изображения по отрезку известной длины в миллиметрах.
- Нужно использовать эту калибровку, чтобы показывать площадь текущего контура не только в пикселях, но и в квадратных миллиметрах.

Область изменений:
- Расчёт свойств изображения.
- Панель "Свойства изображения", группа "Информация о контуре".
- Обновление UI при изменении контура и калибровки.
- Экспорт свойств изображения, если он использует тот же список вычисляемых свойств.
- Тесты расчёта, UI-состояний и экспорта свойств.

Требования к пользовательскому сценарию:
- В панели "Свойства изображения" в группе "Информация о контуре" добавить новое свойство площади контура в квадратных миллиметрах.
- Название свойства должно быть понятным и соответствовать стилю интерфейса, например:
  - "Площадь контура";
  - или "Площадь контура, мм²";
  - или "Площадь, мм²".
- Если у выбранного изображения есть контур и корректная калибровка, значение должно показывать вычисленную площадь в `мм²`.
- Если контур есть, но калибровка не задана, в поле значения нужно показать понятное сообщение, например:
  - "калибровка не произведена";
  - или "нет калибровки".
- Если контур отсутствует, значение должно показывать пустое состояние в стиле остальных вычисляемых свойств, например `-`.
- При переключении между изображениями значение площади должно соответствовать выбранному изображению.

Требования к расчёту:
- Площадь контура в пикселях должна рассчитываться тем же способом, который уже используется для свойства "Количество пикселов контура", если это свойство фактически считает площадь маски контура.
- Для перевода площади в квадратные миллиметры использовать масштаб текущей калибровки изображения:
  - `pixels_per_mm = pixel_length / real_length_mm`;
  - `mm_per_pixel = real_length_mm / pixel_length`;
  - `area_mm2 = area_pixels * mm_per_pixel * mm_per_pixel`;
  - эквивалентно: `area_mm2 = area_pixels / (pixels_per_mm * pixels_per_mm)`.
- Использовать только калибровку выбранного изображения, а не калибровку другого изображения или проекта в целом.
- Если калибровка повреждена, неполная, имеет нулевую длину или не проходит существующую валидацию, площадь в `мм²` не рассчитывать.
- Если площадь контура в пикселях равна нулю или контур некорректен, показывать пустое состояние или понятное сообщение в стиле текущих свойств.
- Значение для отображения нужно округлять до разумного количества знаков, чтобы оно было читаемым:
  - для крупных значений можно показывать 1-2 знака после запятой;
  - для малых значений не терять значащие цифры;
  - не показывать длинный хвост float.

Требования к обновлению:
- Площадь в `мм²` должна пересчитываться после каждого изменения контура:
  - построение нового контура;
  - загрузка аннотации;
  - ручное редактирование узлов;
  - добавление или удаление узлов;
  - удаление контура.
- Площадь должна пересчитываться после изменения калибровки:
  - создание новой калибровки;
  - перемещение узлов калибровочного отрезка;
  - сброс калибровки.
- При изменении выбранного изображения, закрытии проекта или удалении изображения значение должно очищаться корректно.
- Пересчёт не должен требовать ручного обновления панели пользователем.

Требования к интерфейсу:
- Новое свойство должно быть добавлено рядом с существующими свойствами контура, логично после:
  - "Количество пикселов контура";
  - или рядом с "Масштаб".
- Формат значения при успешном расчёте должен быть человекочитаемым, например:
  - `123.45 мм²`;
  - `0.083 мм²`;
  - `12 мм²`.
- Если калибровка отсутствует, текст "калибровка не произведена" должен быть виден в панели свойств и не должен обрезаться в узкой панели.
- Существующая группа "Информация о контуре" должна продолжать сворачиваться и разворачиваться.
- Новое свойство не должно менять визуальное поведение других свойств изображения.

Требования к данным:
- Новое значение является вычисляемым и не должно сохраняться в JSON проекта.
- В JSON по-прежнему сохраняются только исходные данные: контур и калибровка.
- При открытии старых проектов без калибровки или без контура приложение должно работать без ошибок.
- При экспорте свойств изображения в Excel, если экспорт покрывает вычисляемые свойства панели, добавить новое свойство в список доступных для экспорта.

Требования к ошибкам и пустым состояниям:
- Нет выбранного изображения: значение не показывается вместе с остальной панелью или остаётся в пустом состоянии.
- Нет контура: `-`.
- Есть контур, но нет калибровки: "калибровка не произведена".
- Есть контур и повреждённая калибровка: показать понятное состояние, не падать.
- Есть калибровка, но нет контура: `-`.
- Удаление или сброс калибровки должно сразу заменить числовую площадь на сообщение о том, что калибровка не произведена, если контур всё ещё есть.

Рекомендации по реализации:
- Переиспользовать существующий расчёт количества пикселов контура или маски контура, чтобы площадь в `мм²` соответствовала уже отображаемому pixel-area.
- Добавить небольшой helper для форматирования площади в `мм²`, аналогично существующим helper-функциям форматирования масштаба или числовых свойств.
- Не дублировать расчёт маски, если в `canvas` или `main_window` уже есть метод, возвращающий количество пикселов контура.
- Использовать методы `ImageCalibration.mm_per_pixel()` или `pixels_per_mm()`, если они уже есть в модели.
- Обновлять свойство в том же месте, где обновляются "Количество пикселов контура" и "Масштаб".
- Если есть список `IMAGE_PROPERTY_EXPORT_KEYS` или аналогичный список для экспорта, добавить туда новый ключ без нарушения порядка существующих колонок.
- Сохранить текущие паттерны сигналов `contour_geometry_changed` и `calibration_geometry_changed`.

Критерии приёмки:
- В группе "Информация о контуре" панели "Свойства изображения" есть новое свойство площади контура в `мм²`.
- Если выбранное изображение имеет контур и калибровку, отображается корректная площадь в квадратных миллиметрах.
- Если контур есть, а калибровки нет, отображается сообщение "калибровка не произведена" или аналогичное по смыслу.
- Если контура нет, отображается `-`.
- После редактирования контура площадь пересчитывается автоматически.
- После создания, изменения или сброса калибровки площадь пересчитывается автоматически.
- При переключении между изображениями значение площади не переносится с предыдущего изображения.
- Значение площади не сохраняется в JSON проекта.
- Если экспорт свойств изображения доступен, новая площадь присутствует в списке экспортируемых свойств и корректно попадает в Excel.
- Существующие свойства контура, калибровки, цветовые свойства, метаданные и экспорт продолжают работать.
- Существующие тесты проходят.
- Добавлены или обновлены тесты на:
  - отображение `-` без контура;
  - сообщение об отсутствии калибровки при наличии контура;
  - корректный расчёт площади при наличии контура и калибровки;
  - пересчёт после изменения контура;
  - пересчёт после изменения или сброса калибровки;
  - отсутствие вычисленной площади в JSON;
  - экспорт площади в Excel, если экспорт свойств изображения поддерживается.
