Задача: добавить в проект новый тип измерений "Отрезки": создание на канвасе двумя кликами, отображение подписей точек и длины, управление в свойствах изображения, удаление, иконки команд и сохранение в JSON проекта.

Контекст:
- Проект MagicBorder - настольное приложение на PyQt5.
- Измерения изображения уже представлены в модели проекта через блок `measurements`.
- Сейчас в `src/magicborder/models.py` есть:
  - `ProjectImageMeasurements`;
  - `ProjectAngleMeasurement`;
  - `ProjectImageRecord.measurements.angles`.
- В панели "Свойства изображения" уже есть группа верхнего уровня "Измерения".
- Внутри неё уже есть подгруппа "Углы", которая отображает динамическую коллекцию углов.
- Углы уже умеют:
  - создаваться на канвасе;
  - отображаться как проектные сущности;
  - сохраняться в JSON;
  - загружаться из JSON;
  - удаляться;
  - синхронизироваться между `ImageCanvas`, `MainWindow` и панелью свойств.
- Нужно добавить аналогичную подгруппу "Отрезки", но с логикой измерения длины между двумя точками.

Область изменений:
- `src/magicborder/models.py`:
  - модель проектного измерения отрезка;
  - контейнер `ProjectImageMeasurements`;
  - сериализация и загрузка JSON;

- `src/magicborder/canvas.py`:
  - инструмент создания отрезка двумя кликами;
  - preview отрезка между первым кликом и указателем мыши;
  - графика завершённого отрезка;
  - draggable-узлы отрезка;
  - подписи начала и конца отрезка;
  - подпись длины отрезка;
  - удаление выбранного отрезка.
- `src/magicborder/main_window.py`:
  - команды создания и удаления отрезка;
  - подгруппа "Измерения" -> "Отрезки";
  - редактируемые поля подписей первой и второй точек;
  - синхронизация canvas <-> модель <-> панель свойств;
  - сохранение проекта после изменения коллекции или подписей.
- `src/magicborder/icons.py` и `src/magicborder/assets/icons`:
  - иконка команды создания отрезка;
  - иконка команды удаления отрезка.
- Тесты:
  - `tests/test_project_models.py`;
  - `tests/test_canvas.py`;
  - `tests/test_project_properties.py`;
  - `tests/test_icons.py`.

Не входит в задачу:
- Не менять поведение инструмента углов.
- Не менять формат сохранения углов.
- Не менять расчёт калибровки и существующий UI калибровки.
- Не менять геометрию главного контура и аннотации.
- Не добавлять измерения площадей, маркеры или произвольные полилинии.
- Не сохранять вычисляемую длину отрезка в JSON, если она может быть получена из координат и калибровки.
- Не ломать старые проекты без блока `segments`.

Требования к модели данных:
- Добавить проектную модель отрезка, например `ProjectSegmentMeasurement`.
- У каждого отрезка должен быть стабильный `id`, сохраняемый в JSON.
- Геометрия отрезка должна хранить две точки:
  - `start`;
  - `end`.
- Для подписей точек добавить два редактируемых строковых поля:
  - `start_label`;
  - `end_label`.
- Рекомендуемая JSON-структура внутри `measurements`:
  ```json
  {
    "measurements": {
      "angles": [],
      "segments": [
        {
          "id": "segment-...",
          "start": {"x": 10.0, "y": 20.0},
          "end": {"x": 80.0, "y": 20.0},
          "start_label": "A",
          "end_label": "B"
        }
      ]
    }
  }
  ```
- Если нужны примечания по аналогии с углами, можно добавить `note`, но не смешивать его с подписями точек. Если `note` не нужен для текущего UI, не добавлять лишнее поле.
- Если блок `segments` отсутствует в старом проекте, он считается пустым.
- Если отдельный отрезок в JSON некорректен, загрузка проекта не должна падать целиком. Пропустить только некорректный отрезок, как сейчас пропускаются некорректные углы.
- `ProjectImageMeasurements.to_dict()` должен сохранять:
  - `angles`;
  - `segments`;
  - будущие неизвестные группы из `extra_groups`.
- При round-trip проекта неизвестные будущие ключи в `measurements` не должны теряться.

Требования к панели "Свойства изображения":
- В группе "Измерения" добавить подгруппу "Отрезки" сразу после подгруппы "Углы".
- Если отрезков нет, подгруппа "Отрезки" должна показывать пустое состояние, например "Нет отрезков".
- Каждый отрезок отображать как вложенную группу:
  - `Отрезок 1`;
  - `Отрезок 2`;
  - и так далее.
- Номер отрезка должен соответствовать порядку в `record.measurements.segments`.
- Внутри группы отрезка отобразить:
  - `ID`;
  - `Длина`;
  - `Первая точка`;
  - `Вторая точка`;
  - редактируемое поле `Подпись первой точки`;
  - редактируемое поле `Подпись второй точки`;
  - команду `Удалить`.
- Координаты точек можно показывать в том же формате, который используется для углов.
- Поле `Длина` должно быть вычисляемым:
  - всегда показывать длину в пикселях;
  - если есть калибровка текущего изображения, дополнительно показывать длину в мм;
  - если калибровки нет, явно показывать только пиксели или пиксели плюс текст "калибровка не произведена" в стиле существующего UI.
- Редактирование подписей точек должно:
  - обновлять модель проекта;
  - обновлять соответствующие подписи на канвасе;
  - планировать сохранение проекта;
  - не менять координаты и `id`.
- Если подпись точки пустая:
  - на канвасе можно не показывать подпись этой точки;
  - либо показывать fallback `Точка 1` / `Точка 2`. Выбрать один вариант и закрепить тестом.
- Удаление отрезка из панели свойств должно:
  - удалить сущность из `record.measurements.segments`;
  - удалить графику с канваса, если это текущее изображение;
  - обновить подгруппу "Отрезки";
  - обновить доступность команды "Удалить отрезок";
  - запланировать сохранение проекта.

Требования к инструменту на канвасе:
- Добавить команду/действие "Отрезок".
- После вызова команды пользователь должен указать две точки:
  - первый клик задаёт первую точку;
  - до второго клика показывается preview-линия от первой точки до текущего положения указателя;
  - второй клик завершает отрезок.
- Preview должен быть визуально понятным и отличаться от завершённого отрезка.
- Если второй клик совпадает с первой точкой или длина слишком мала, не создавать отрезок и показать понятное сообщение.
- После завершения отрезка режим создания может:
  - остаться активным для создания следующего отрезка, как у углов;
  - либо завершиться. Выбрать поведение, согласованное с текущим UX измерений, и закрепить тестом.
- Завершённый отрезок на канвасе должен отображать:
  - линию между `start` и `end`;
  - draggable-узел в первой точке;
  - draggable-узел во второй точке;
  - подпись первой точки рядом со `start`, если она задана;
  - подпись второй точки рядом с `end`, если она задана;
  - подпись длины около середины отрезка.
- Узлы отрезка должны перемещаться мышью.
- При перемещении любого узла:
  - координаты в модели должны обновляться;
  - длина должна пересчитываться;
  - подпись длины на канвасе должна обновляться;
  - панель свойств должна обновляться;
  - проект должен планироваться к сохранению.
- Если есть калибровка, подпись длины должна обновляться при изменении калибровки:
  - после создания калибровочного отрезка;
  - после изменения длины калибровки в свойствах;
  - после сброса калибровки.
- Команда "Удалить отрезок" должна удалять выбранный отрезок.
- Критерий выбора для удаления нужно сделать очевидным и тестируемым:
  - например удалять отрезок, если выбран один из его endpoint-узлов;
  - либо если выбран сам line-item отрезка, если он будет selectable.
- Удаление отрезка не должно удалять углы, контур или калибровку.

Требования к подписи длины:
- В пикселях использовать короткий и стабильный формат, например:
  - `120 px`;
  - `120.5 px`, если нужна дробная часть.
- В миллиметрах при наличии калибровки показывать вторую величину, например:
  - `120 px / 10 мм`;
  - `120 px / 10.5 мм`.
- Округление должно быть предсказуемым и единым между canvas и панелью свойств.
- Если калибровка отсутствует, не показывать фиктивные миллиметры.
- Длину в JSON не сохранять, потому что она вычисляется из координат и текущей калибровки.

Требования к синхронизации:
- Источником истины для отрезков текущего изображения должна быть проектная модель `ProjectImageRecord.measurements.segments`.
- `ImageCanvas` должен уметь принимать и отдавать canvas-записи отрезков с `id`, координатами и подписями.
- В `MainWindow` добавить хранение/обновление отрезков по аналогии с `_store_current_angle_measurements`.
- При переключении изображений:
  - на канвасе отображаются только отрезки выбранного изображения;
  - в панели свойств отображаются только отрезки выбранного изображения.
- При открытии проекта с сохранёнными отрезками они должны восстановиться на канвасе и в панели свойств.
- При создании, перемещении, переименовании подписей и удалении отрезков должен запускаться обычный механизм autosave проекта.
- Редактирование подписей точек не должно менять порядок отрезков.
- После удаления отрезка оставшиеся отрезки в панели должны быть перенумерованы без пропусков.
