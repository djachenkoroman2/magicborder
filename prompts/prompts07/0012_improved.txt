Задача: синхронизировать визуальную подсветку главного контура с работой пользователя на canvas и в панели свойств.

Исходная формулировка:
"Необходимо внести изменения в поведение интерфейса:
1. Поведение при работе с элементами измерений: если мы работаем с основным контуром то он считается выделенным, поэтому необходимо соответсвующие его линии делать более толстыми как в случае нажатия в окне свойств изображенияю."

Контекст проекта:
- MagicBorder - настольное приложение на PyQt5.
- Canvas реализован в `src/magicborder/canvas.py`, класс `ImageCanvas`.
- Основное окно реализовано в `src/magicborder/main_window.py`.
- Панель "Свойства изображения" строится через `PropertyBrowser` в `src/magicborder/property_browser.py`.
- Главный контур на canvas сейчас состоит из:
  - `_path_item: QGraphicsPathItem` - линия замкнутого контура;
  - `_contour_points` - точки контура;
  - `_handles: list[NodeHandleItem]` - узлы контура.
- Узлы главного контура редактируются через `NodeHandleItem`:
  - перетаскивание вызывает `ImageCanvas.handle_moved(...)`;
  - правый клик удаляет узел через `ImageCanvas.remove_node(...)`.
- Добавление узла контура уже реализовано через `ImageCanvas.insert_node_near(...)`.
- Удаление выбранных узлов уже реализовано через `ImageCanvas.delete_selected_nodes(...)`.
- Видимость главного контура управляется через:
  - `ImageCanvas.is_contour_visible()`;
  - `ImageCanvas.set_contour_visible(...)`;
  - `ImageCanvas._apply_contour_visibility()`;
  - checkbox `property_contour_visible` в панели свойств изображения.
- Для углов и отрезков уже есть механизм визуальной подсветки:
  - `highlight_angle_measurement(...)`;
  - `highlight_segment_measurement(...)`;
  - `clear_measurement_highlight()`;
  - `highlighted_angle_id()`;
  - `highlighted_segment_id()`;
  - утолщение линий/дуг/handles через highlighted-состояние.
- Сейчас этот механизм не покрывает главный контур.

Главное требование:
- Если пользователь работает с главным контуром на canvas, главный контур должен считаться активным/выделенным.
- Активный главный контур должен визуально подсвечиваться утолщением линии контура и усилением узлов.
- Подсветка должна быть такой же временной UI-подсказкой, как highlighted-состояние углов и отрезков:
  - не сохраняется в проект;
  - не попадает в JSON;
  - не меняет видимость контура;
  - не меняет геометрию, кроме обычных действий редактирования.
- Клик по строкам группы `Информация о главном контуре` в панели "Свойства изображения" тоже должен подсвечивать главный контур на canvas.
- Одновременно на canvas должен быть подсвечен максимум один активный объект:
  - либо главный контур;
  - либо один угол;
  - либо один отрезок.

Область изменений:
- `src/magicborder/canvas.py`:
  - добавить highlighted-состояние для главного контура;
  - обновить отрисовку `_path_item` и `NodeHandleItem` для обычного и highlighted-состояния;
  - синхронизировать подсветку при выборе, перемещении, добавлении и удалении узлов контура;
  - сохранить существующую логику редактирования контура.
- `src/magicborder/main_window.py`:
  - добавить реакцию на клик по группе и строкам главного контура в панели "Свойства изображения";
  - обновить helper очистки подсветки так, чтобы он очищал не только измерения, но и главный контур;
  - сохранить существующую подсветку углов и отрезков.
- `tests/test_canvas.py`:
  - добавить тесты для highlighted-состояния главного контура на canvas.
- `tests/test_project_properties.py`:
  - добавить или обновить тесты клика по строкам главного контура в панели свойств.

Не входит в задачу:
- Не менять формат проектного JSON.
- Не сохранять highlighted-состояние главного контура в проект.
- Не менять формат Excel-экспорта.
- Не менять состав, порядок или значения строк панели "Свойства изображения", кроме технических ключей строк, если они нужны для клика.
- Не менять логику создания, детекта, сохранения или удаления главного контура.
- Не менять временную видимость контура, углов или отрезков.
- Не делать главный контур всегда толстым: утолщение должно быть только для активного/выделенного состояния.
- Не включать автоматически скрытый контур только из-за highlighted-состояния.
- Не подсвечивать главный контур при клике по строкам других групп, например RGB, Lab, Локация или Дополнительно.
- Не добавлять новые toolbar-команды, иконки или зависимости.

Требования к поведению на canvas:
- Если пользователь выбирает любой `NodeHandleItem` главного контура, весь главный контур становится highlighted.
- Если пользователь перетаскивает любой узел главного контура, контур становится highlighted и остаётся highlighted после перемещения.
- Если пользователь добавляет новый узел через `insert_node_near(...)`, главный контур становится highlighted.
- Если пользователь удаляет узел через правый клик или `delete_selected_nodes()`, главный контур остаётся highlighted, если контур всё ещё существует.
- Если главный контур очищен через `clear_contour()`, highlighted-состояние контура должно сбрасываться.
- Если загружен новый контур через `set_contour(...)`, по умолчанию он не обязан становиться highlighted, если только это не результат пользовательского действия, которое уже считается работой с контуром.
- Если контур скрыт через `set_contour_visible(False)`, highlighted-состояние не должно автоматически включать видимость.
- Если контур был highlighted, затем скрыт, а потом снова показан, допустимо сохранить highlighted-состояние и показать его утолщённым, если это не ломает текущую логику очистки.
- Если пользователь кликает по пустому месту canvas и выделение узлов контура снимается, подсветку контура нужно очистить, если нет другого активного источника подсветки.

Требования к визуальному виду главного контура:
- Обычный вид главного контура должен остаться визуально близким к текущему:
  - цвет линии контура не менять без необходимости;
  - обычная толщина линии остаётся прежней или эквивалентной текущей.
- В highlighted-состоянии линия `_path_item` должна быть заметно толще обычной.
- Рекомендуемый ориентир:
  - обычная толщина линии контура: текущие `2.0`;
  - highlighted-толщина: примерно `4.0-4.6`, близко к `MEASUREMENT_HIGHLIGHT_LINE_WIDTH`.
- Узлы контура в highlighted-состоянии должны визуально усиливаться:
  - можно увеличить толщину белой обводки;
  - можно поднять `zValue`, чтобы узлы не терялись за другими элементами;
  - не нужно менять размеры узлов, если это ухудшит точность клика.
- Утолщённая линия не должна перекрывать handles так, чтобы ими стало трудно пользоваться.
- Для скрытого контура `_path_item` и handles остаются невидимыми независимо от highlighted-состояния.

Совместимость с подсветкой углов и отрезков:
- Если подсвечен главный контур, а пользователь выбирает угол или отрезок, подсветка главного контура должна сброситься.
- Если подсвечен угол или отрезок, а пользователь выбирает или редактирует главный контур, подсветка измерения должна сброситься.
- Методы `highlight_angle_measurement(...)` и `highlight_segment_measurement(...)` должны очищать highlighted-состояние главного контура.
- Новый метод подсветки главного контура должен очищать highlighted-состояние угла и отрезка.
- `clear_measurement_highlight()` можно:
  - оставить только для измерений и добавить отдельный `clear_canvas_highlight()`;
  - или аккуратно расширить/переименовать общий механизм, сохранив совместимость существующих вызовов и тестов.
- Существующие тесты для подсветки углов и отрезков должны продолжать проходить.

Требования к панели "Свойства изображения":
- Клик по группе `Информация о главном контуре` должен подсвечивать главный контур, если он есть на canvas и видимость не запрещает отображение.
- Клик по дочерним строкам этой группы тоже должен подсвечивать главный контур:
  - `Аннотация`;
  - `Показывать контур`;
  - `Количество узлов контура`;
  - `Количество пикселов контура`;
  - `Площадь контура, мм²`.
- Клик по строкам угла или отрезка должен продолжать подсвечивать соответствующее измерение.
- Клик по обычным строкам не-контурных групп должен очищать активную подсветку.
- Клик по пустой области `PropertyBrowser` должен очищать активную подсветку.
- Если в панели у строк главного контура сейчас нет технических keys, добавить их аккуратно:
  - например group key `contour`;
  - leaf keys `contour:annotation`, `contour:visible`, `contour:point_count`, `contour:pixel_count`, `contour:area_mm2`.
- Не завязывать новую логику только на русские labels, если можно использовать keys через `Qt.UserRole + 1`.
- Если выбранного изображения или контура нет, клик по строкам главного контура не должен падать и может просто очистить подсветку.

Рекомендации по реализации в `ImageCanvas`:
- Ввести явное состояние, например:
  - `_contour_highlighted: bool`;
  - `is_contour_highlighted() -> bool`;
  - `highlight_contour() -> bool`;
  - `clear_contour_highlight() -> bool`.
- Добавить общий метод очистки активной подсветки, если это упростит поддержку:
  - `clear_canvas_highlight()`;
  - или `_clear_active_highlight()`.
- Для применения визуального состояния удобно добавить:
  - `_apply_contour_highlight()`;
  - `_refresh_contour_visual_state()`.
- `NodeHandleItem` можно дополнить методом:
  - `set_highlighted(highlighted: bool)`.
- В `NodeHandleItem.itemChange(...)` добавить обработку `ItemSelectedHasChanged`, чтобы выбор узла уведомлял canvas.
- В `ImageCanvas.handle_moved(...)` перед или после обновления точки вызвать подсветку главного контура.
- В `remove_node(...)`, `delete_selected_nodes()` и `insert_node_near(...)` подсвечивать контур при успешном пользовательском изменении.
- В `clear_contour()` обязательно сбрасывать highlighted-состояние контура.
- В `_rebuild_handles()` после создания handles повторно применять highlighted-состояние, чтобы оно не терялось при пересборке.
- В `_apply_contour_visibility()` не сбрасывать геометрию и не менять highlighted-состояние без необходимости.
- Следить за `_suppress_handle_events`, чтобы программная пересборка handles не включала подсветку как пользовательское действие.

Рекомендации по реализации в `MainWindow`:
- Переименовать helper `_clear_image_property_measurement_highlight()` во что-то более общее, если он начнёт очищать и контур:
  - например `_clear_image_property_canvas_highlight()`.
- Расширить `_handle_image_property_item_clicked(...)`:
  - сначала определить, относится ли item или его parent к главному контуру;
  - затем сохранить текущую обработку `angle:<id>` и `segment:<id>`;
  - иначе очистить подсветку.
- Можно добавить helper:
  - `_canvas_reference_from_property_item(item) -> tuple[str, str | None] | None`;
  - где типы: `contour`, `angle`, `segment`.
- Для группы главного контура лучше использовать key `contour`, чтобы parent traversal работал так же, как для `angle:<id>` и `segment:<id>`.
- После изменения подсветки вызывать `_update_action_states()`, как это уже делается для измерений.

Side effects:
- Подсветка главного контура не должна запускать autosave.
- Подсветка главного контура не должна менять project model.
- Подсветка главного контура не должна менять annotation points.
- Подсветка главного контура не должна менять checkbox `property_contour_visible`.
- Подсветка главного контура не должна менять выделение строк в `PropertyBrowser`, если такого поведения сейчас нет.
- Подсветка главного контура не должна автоматически выделять все узлы контура.
- Обычное выделение узлов для удаления должно продолжать работать как раньше.

Проверки вручную:
- Открыть изображение с главным контуром.
- Кликнуть узел главного контура:
  - линия контура становится толще;
  - узлы визуально усиливаются;
  - редактирование узла работает как раньше.
- Перетащить узел главного контура:
  - контур остаётся утолщённым во время и после перемещения.
- Добавить узел двойным кликом рядом с линией контура:
  - контур становится highlighted;
  - новый узел добавляется как раньше.
- Удалить узел правым кликом:
  - узел удаляется;
  - контур остаётся highlighted, если он ещё существует.
- Кликнуть строку `Информация о главном контуре` или `Количество узлов контура` в панели свойств:
  - главный контур подсвечивается.
- Кликнуть строку угла или отрезка:
  - подсветка главного контура сбрасывается;
  - подсвечивается выбранное измерение.
- Скрыть контур checkbox-ом `Показывать контур`:
  - контур скрывается;
  - подсветка не делает его видимым самопроизвольно.
- Показать контур обратно:
  - контур отображается корректно;
  - приложение не меняет JSON только из-за подсветки.

Критерии готовности:
- Работа с главным контуром на canvas включает визуальную подсветку главного контура.
- Линия главного контура в highlighted-состоянии заметно толще обычной.
- Узлы главного контура в highlighted-состоянии визуально усилены и остаются удобными для редактирования.
- Клик по группе и строкам главного контура в панели "Свойства изображения" подсвечивает главный контур.
- Подсветка главного контура взаимно исключается с подсветкой углов и отрезков.
- Подсветка не меняет проектную модель, JSON, видимость и Excel-экспорт.
- Существующее редактирование, добавление, удаление и скрытие главного контура работает как раньше.
- Проходят тесты:
  - `env PYTHONPATH=src uv run pytest tests/test_canvas.py tests/test_project_properties.py`;
  - желательно также `env PYTHONPATH=src uv run pytest`.
