Задача: добавить в свойства изображения управление видимостью главного контура на канвасе.

Контекст:
- Проект MagicBorder - настольное приложение на PyQt5.
- Правая/левая панель "Свойства изображения" строится в `src/magicborder/main_window.py`.
- Группа свойств главного контура уже называется "Информация о главном контуре".
- В этой группе сейчас отображаются:
  - "Аннотация";
  - "Количество узлов контура";
  - "Количество пикселов контура";
  - "Площадь контура, мм²".
- Главный контур на канвасе реализован в `src/magicborder/canvas.py`:
  - линия/полигон контура отображается через `_path_item`;
  - draggable-узлы контура хранятся в `_handles`;
  - геометрия контура хранится в `_contour_points`;
  - наличие контура определяется через `has_contour()`;
  - расчёты пикселов контура выполняются через `contour_rgb_pixels()` и `_contour_mask()`.
- Нужно добавить UI-свойство, которое управляет только видимостью контура на канвасе.

Область изменений:
- `src/magicborder/canvas.py`:
  - публичный API для чтения и изменения видимости главного контура;
  - применение видимости к `_path_item` и узлам контура;
  - сохранение корректного поведения при создании, загрузке, очистке и редактировании контура.
- `src/magicborder/main_window.py`:
  - новый виджет в группе "Информация о главном контуре";
  - синхронизация checkbox/toggle с текущим выбранным изображением и состоянием канваса.
- `tests/test_canvas.py` и `tests/test_project_properties.py`.

Не входит в задачу:
- Не удалять контур при выключении видимости.
- Не менять геометрию контура, координаты узлов и формат аннотации.
- Не менять алгоритмы построения, детектирования, удаления и сохранения контура.
- Не менять расчёт количества пикселов контура, площади, средних цветов и гистограмм.
- Не менять JSON-структуру проекта, если в проекте нет отдельного слоя UI-настроек. Видимость контура считать настройкой отображения, а не частью аннотации.
- Не скрывать и не менять другие элементы канваса:
  - калибровочный отрезок;
  - измерения углов;
  - подписи измерений;
  - изображение.

Требования к UI:
- В группе "Информация о главном контуре" добавить редактируемое свойство:
  - название: `Показывать контур`;
  - рекомендуемый виджет: `QCheckBox` или другой стандартный бинарный toggle.
- Свойство должно располагаться рядом с остальными свойствами главного контура, предпочтительно после поля "Аннотация" и до "Количество узлов контура".
- Когда у выбранного изображения есть контур, checkbox должен быть доступен.
- Когда у выбранного изображения нет контура или изображение не выбрано, checkbox должен быть отключён.
- По умолчанию для изображения с контуром контур должен быть видим.
- Состояние checkbox должно отражать фактическое состояние видимости на канвасе.
- Переключение checkbox должно сразу менять отображение контура на канвасе без перезагрузки изображения.
- Отключённый checkbox не должен выглядеть как команда удаления контура: пользователь должен понимать, что это только видимость.

Требования к поведению канваса:
- При `Показывать контур = включено` на канвасе должны быть видны:
  - линия/полигон контура;
  - draggable-узлы контура.
- При `Показывать контур = выключено` на канвасе должны быть скрыты:
  - линия/полигон контура;
  - draggable-узлы контура.
- Скрытый контур должен оставаться в памяти:
  - `has_contour()` продолжает возвращать `True`;
  - `contour_points()` продолжает возвращать точки;
  - `contour_rgb_pixels()` продолжает работать;
  - сохранение проекта/аннотации продолжает сохранять контур.
- Скрытый контур не должен мешать пользователю визуально:
  - узлы не должны оставаться видимыми;
  - скрытые узлы не должны казаться выбранными на экране;
  - если выбранные узлы были скрыты, их выделение желательно сбросить.
- При повторном включении видимости контур и узлы должны появиться на прежних местах.
- При создании нового контура, открытии аннотации или детектировании контура видимость должна становиться включённой, если нет явного сохранённого session-состояния для текущего изображения.
- При удалении или очистке контура checkbox должен стать отключённым, а состояние канваса должно быть консистентным.
- При переключении изображения:
  - если у нового изображения есть контур, checkbox доступен;
  - если нет контура, checkbox отключён;
  - контур нового изображения по умолчанию видим.

Рекомендации по реализации:
- В `ImageCanvas` добавить методы, например:
  - `is_contour_visible() -> bool`;
  - `set_contour_visible(visible: bool) -> None`;
  - при необходимости `_apply_contour_visibility()`.
- Видимость применять не через удаление объектов из сцены, а через `setVisible(...)`.
- `_refresh_path()` должен учитывать флаг видимости, чтобы после пересчёта path скрытый контур не появлялся самопроизвольно.
- `_rebuild_handles()` должен учитывать флаг видимости, чтобы новые handles не становились видимыми при выключенном контуре.
- `clear_contour()` должен сбрасывать состояние к безопасному значению, например "видим", но без отображения пустого контура.
- `set_contour(...)` должен создавать/обновлять контур и показывать его по умолчанию.
- В `MainWindow` создать поле, например `self.property_contour_visible = QCheckBox(...)`.
- Подключить checkbox к обработчику, например `_handle_contour_visibility_changed`.
- В `_update_project_properties()` или рядом с ним обновлять:
  - checked-состояние;
  - enabled-состояние;
  - блокировать сигнал через `QSignalBlocker`, чтобы обновление UI не вызывало лишних обработчиков.
- Не вызывать `_save_current_project_annotation()` и `_schedule_project_save()` при простом переключении видимости, если видимость не сохраняется в проект.

Требования к тестам:
- В `tests/test_canvas.py` добавить тест, что:
  - после `set_contour(...)` контур и handles видимы;
  - после `set_contour_visible(False)` `_path_item` и все handles скрыты;
  - `has_contour()` остаётся `True`;
  - `contour_points()` возвращает прежние точки;
  - после `set_contour_visible(True)` path и handles снова видимы.
- Добавить тест, что скрытый контур остаётся скрытым после перемещения узла или `_refresh_path()`.
- Добавить тест, что после `clear_contour()` и последующего `set_contour(...)` новый контур снова видим по умолчанию.
- В `tests/test_project_properties.py` добавить UI-тест, что:
  - в группе "Информация о главном контуре" появилась строка "Показывать контур";
  - checkbox выключен/disabled, когда у изображения нет контура;
  - checkbox enabled и checked, когда у изображения есть контур;
  - снятие галочки скрывает контур на канвасе, но не удаляет `record.annotation`;
  - повторная установка галочки показывает контур обратно.
- Проверить, что переключение видимости не запускает сохранение проекта, если видимость не должна сохраняться в JSON.
- Тесты не должны требовать видимого GUI-окна; использовать существующий offscreen-подход.

Критерии приёмки:
- В группе "Информация о главном контуре" есть свойство "Показывать контур".
- Пользователь может скрыть и снова показать главный контур на канвасе.
- При скрытии исчезают и линия контура, и узлы редактирования.
- Скрытие не удаляет контур и не меняет аннотацию.
- Расчёты по контуру, экспорт, сохранение и загрузка проекта продолжают работать.
- Для изображений без контура управление видимостью недоступно.
- Новый или загруженный контур по умолчанию видим.
- Существующие тесты проходят; добавлены тесты для свойства видимости контура.
