Задача: добавить команды "показать все" / "скрыть все" для элементов canvas и визуальную подсветку измерения при выборе его в панели свойств.

Исходная формулировка:
"В интерфейсе необходимо добавить две команды:
1. Команда которая включает отборажение всех элементов на канвасе (работа со свойством видимости)
2. Команда которая выключает отображение всех элементов на канвасе
3. В итемах элементов после сброса или влючения есть возможность включать или выключать видимость элемента на канвасе.
4. Также вынести эти команды на панель инструментов отделив их от остальных вертикальнвми линиями
5. Для обоих команд разработать иконки в формате SVG в соответствии со стилистикой проекта.
6. Дополнительно на панели инструментов отдели веритикальной чертой команды "Сохранить аннотацию" и "Открыть аннотацию".
7. Также добавить следующее поведение интерфейса: при нажатии на конкретные итемы измерений (конкретные углы или отрезки) в окне свойств изображения на канвасе этот элемент в части изображения линий и узлов должен  изменить толщину отображаемых линий чтобы его можно было пользователю визуально отделить от остальных элементов канваса."

Контекст проекта:
- MagicBorder - настольное приложение на PyQt5.
- Основное окно: `src/magicborder/main_window.py`.
- Canvas: `src/magicborder/canvas.py`, класс `ImageCanvas`.
- Панель "Свойства изображения" строится через `PropertyBrowser` из `src/magicborder/property_browser.py`.
- Действия toolbar создаются в `MainWindow._create_actions()` и размещаются в `MainWindow._create_toolbar()`.
- Визуальные параметры действий и SVG-иконки описаны в `src/magicborder/icons.py`:
  - `ACTION_VISUALS`;
  - `load_icon(...)`;
  - `apply_action_visual(...)`;
  - `ICON_DIR = src/magicborder/assets/icons`.
- Toolbar сейчас горизонтальный, поэтому `toolbar.addSeparator()` отображается как вертикальная разделительная линия.
- Для главного контура уже есть временная видимость:
  - checkbox `property_contour_visible`;
  - handler `_handle_contour_visibility_changed(...)`;
  - canvas API `set_contour_visible(...)`, `is_contour_visible()`.
- Для измерений уже есть временная видимость:
  - `_angle_visibility_fields`;
  - `_segment_visibility_fields`;
  - `_handle_angle_visibility_changed(...)`;
  - `_handle_segment_visibility_changed(...)`;
  - canvas API `set_angle_measurement_visible(...)`, `is_angle_measurement_visible(...)`;
  - canvas API `set_segment_measurement_visible(...)`, `is_segment_measurement_visible(...)`.
- Временная видимость углов и отрезков не сохраняется в JSON проекта.

Главное требование:
- Добавить две команды для текущего изображения на canvas:
  - показать все управляемые элементы;
  - скрыть все управляемые элементы.
- Под управляемыми элементами в рамках этой задачи понимать:
  - главный контур;
  - все углы;
  - все отрезки.
- После глобального показа или скрытия пользователь должен по-прежнему иметь возможность включать и выключать видимость каждого отдельного элемента через существующие checkbox-строки в панели "Свойства изображения".

Поведение команд видимости:
- Команды работают только для текущего выбранного изображения.
- Команда "Показать все элементы" должна:
  - включить видимость главного контура, если контур существует;
  - включить видимость всех углов текущего изображения;
  - включить видимость всех отрезков текущего изображения;
  - синхронно обновить checkbox `Показывать контур`;
  - синхронно обновить checkbox `Показывать на канвасе` у каждого угла;
  - синхронно обновить checkbox `Показывать на канвасе` у каждого отрезка.
- Команда "Скрыть все элементы" должна:
  - выключить видимость главного контура, если контур существует;
  - выключить видимость всех углов текущего изображения;
  - выключить видимость всех отрезков текущего изображения;
  - синхронно обновить все соответствующие checkbox-поля.
- Если у текущего изображения нет контура, углов или отрезков, команда должна безопасно пропустить отсутствующие элементы.
- Если изображение не выбрано или canvas пустой, actions должны быть disabled.
- После выполнения глобальной команды отдельные checkbox-поля должны оставаться enabled, если они были доступны до команды.
- После глобального скрытия пользователь должен иметь возможность включить отдельный угол или отрезок обратно через checkbox.
- После глобального показа пользователь должен иметь возможность выключить отдельный угол или отрезок через checkbox.
- Команды не должны создавать новый контур, новые углы или новые отрезки.
- Команды не должны менять координаты, имена, подписи или примечания измерений.
- Команды не должны менять выделение canvas.
- Команды не должны запускать autosave только из-за изменения временной видимости.
- Команды не должны сохранять временную видимость в JSON проекта.

Подсветка измерений при клике в панели свойств:
- При клике по конкретному углу в панели "Свойства изображения" соответствующий угол на canvas должен стать highlighted.
- При клике по конкретному отрезку в панели "Свойства изображения" соответствующий отрезок на canvas должен стать highlighted.
- Клик должен работать:
  - по group-строке конкретного угла, например `Угол 1` или пользовательское имя;
  - по любой дочерней строке этого угла, например `ID`, `Значение`, `Примечание`;
  - по group-строке конкретного отрезка;
  - по любой дочерней строке этого отрезка.
- Для определения измерения использовать property keys:
  - `angle:<id>`;
  - `angle:<id>:...`;
  - `segment:<id>`;
  - `segment:<id>:...`.
- Клик по общим группам, placeholder-строкам `Нет углов` / `Нет отрезков`, статическим свойствам изображения или пустому месту должен очищать подсветку.
- Подсветка должна быть только визуальной:
  - не выбирать handles через `setSelected(True)`;
  - не менять результат `has_selected_angle_vertex()`;
  - не менять результат `has_selected_segment_endpoint()`;
  - не включать delete-actions для измерения только из-за клика в панели свойств.
- Если highlighted-измерение скрыто, не нужно автоматически включать его видимость.
- Если пользователь включает скрытое highlighted-измерение через checkbox, оно должно появиться уже в highlighted-виде.
- При выборе другого угла или отрезка предыдущая подсветка должна сбрасываться.
- Одновременно должен быть highlighted максимум один элемент:
  - либо один угол;
  - либо один отрезок.

Рекомендации по реализации подсветки в canvas:

  - `highlight_angle_measurement(angle_id: str | None) -> None`;
  - `highlight_segment_measurement(segment_id: str | None) -> None`;
  - `clear_measurement_highlight() -> None`.
- При подсветке угла:
  - увеличить толщину двух лучей;
  - увеличить толщину дуги;
  - визуально усилить узлы/handles угла через более толстый pen и/или чуть больший z-value;
  - не менять координаты handles.
- При подсветке отрезка:
  - увеличить толщину линии отрезка;
  - визуально усилить оба endpoint handles через более толстый pen и/или чуть больший z-value;
  - не менять координаты endpoints.
- Рекомендуемые толщины:
  - обычные линии оставить как сейчас, около `2.0`;
  - highlighted-линии сделать заметнее, например `4.0` или `4.5`;
  - handles усилить без чрезмерного увеличения размера.
- Для pen-логики лучше добавить helper-методы, чтобы не размазывать цвета и толщины по коду.
- Подсветка должна обновляться после:
  - `_rebuild_angle_graphics()`;
  - `_rebuild_segment_graphics()`;
  - `_refresh_angle_graphic(...)`;
  - `_refresh_segment_graphic(...)`;
  - изменения видимости конкретного измерения.
- При смене изображения или очистке canvas подсветку нужно сбрасывать.
