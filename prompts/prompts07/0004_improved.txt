Задача: добавить для каждого измерения типа "Угол" и "Отрезок" отдельное управление видимостью на канвасе через панель "Свойства изображения".

Исходная формулировка:
"по аналогии с главным контуром необходимо добавить свойство видимости на канвасе и для элементов угол и отрезок"

Контекст проекта:
- MagicBorder - настольное приложение на PyQt5.
- В `src/magicborder/main_window.py` уже есть свойство главного контура:
  - checkbox `property_contour_visible`;
  - строка `Показывать контур` в группе `Информация о главном контуре`;
  - обработчик `_handle_contour_visibility_changed(...)`;
  - синхронизация через `_update_contour_visibility_field(...)`.
- В `src/magicborder/canvas.py` у главного контура уже есть временная canvas-видимость:
  - `_contour_visible`;
  - `is_contour_visible()`;
  - `set_contour_visible(...)`;
  - `_apply_contour_visibility()`.
- Эту идею нужно применить к измерениям, но не делать один общий переключатель. Нужен отдельный переключатель для каждого конкретного угла и каждого конкретного отрезка.

Текущие сущности измерений:
- Углы:
  - проектная модель: `ProjectAngleMeasurement` в `src/magicborder/models.py`;
  - хранилище: `ProjectImageRecord.measurements.angles`;
  - canvas-модель: `AngleMeasurement` в `src/magicborder/canvas.py`;
  - canvas-графика: `AngleGraphics`;
  - построение UI: `_rebuild_angle_measurement_properties(...)` в `src/magicborder/main_window.py`.
- Отрезки:
  - проектная модель: `ProjectSegmentMeasurement` в `src/magicborder/models.py`;
  - хранилище: `ProjectImageRecord.measurements.segments`;
  - canvas-модель: `SegmentMeasurement` в `src/magicborder/canvas.py`;
  - canvas-графика: `SegmentGraphics`;
  - построение UI: `_rebuild_segment_measurement_properties(...)` в `src/magicborder/main_window.py`.
- Измерения уже являются частью JSON проекта через блок `measurements`.
- Новая видимость не должна становиться частью проектной геометрии и не должна добавлять поля в JSON.

Главное требование:
- В группе каждого угла добавить checkbox `Показывать на канвасе`.
- В группе каждого отрезка добавить checkbox `Показывать на канвасе`.
- Переключение checkbox должно сразу скрывать или показывать только соответствующее измерение на канвасе.
- Само измерение должно оставаться в проекте, в памяти, в панели свойств и в сохранённом JSON.

Требования к UI:
- В группе конкретного угла в `Измерения` -> `Углы` добавить строку:
  - label: `Показывать на канвасе`;
  - widget: `QCheckBox`;
  - key: `angle:<id>:visible`.
- В группе конкретного отрезка в `Измерения` -> `Отрезки` добавить строку:
  - label: `Показывать на канвасе`;
  - widget: `QCheckBox`;
  - key: `segment:<id>:visible`.
- Разместить checkbox рядом с основными полями измерения:
  - предпочтительно после `Имя` или после `ID`;
  - не прятать его рядом с кнопкой удаления, чтобы действие не выглядело разрушительным.
- Checkbox должен быть enabled для существующего измерения на текущем изображении.
- По умолчанию checkbox checked для новых и загруженных измерений.
- Если измерение скрыто, его группа в панели свойств должна оставаться видимой и редактируемой.
- Если измерение удалено, его группа и checkbox должны исчезнуть.
- Для хранения ссылок на виджеты допустимо добавить словари наподобие:
  - `_angle_visibility_fields: dict[str, QCheckBox]`;
  - `_segment_visibility_fields: dict[str, QCheckBox]`.
- При перестроении панели использовать `QSignalBlocker` или порядок инициализации "setChecked до connect", чтобы первичная синхронизация checkbox не вызывала лишний обработчик.

Требования к canvas API:
- Добавить методы для углов:
  - `is_angle_measurement_visible(angle_id: str) -> bool`;
  - `set_angle_measurement_visible(angle_id: str, visible: bool) -> bool`.
- Добавить методы для отрезков:
  - `is_segment_measurement_visible(segment_id: str) -> bool`;
  - `set_segment_measurement_visible(segment_id: str, visible: bool) -> bool`.
- `is_*_visible(...)` должен возвращать `False`, если измерение с таким `id` не найдено.
- `set_*_visible(...)` должен:
  - найти измерение по `id`;
  - вернуть `False`, если `id` не найден или состояние не изменилось;
  - обновить состояние и графику;
  - вернуть `True`, если видимость изменилась.
- Видимость применять через `setVisible(...)` у существующих `QGraphicsItem`, а не через удаление из `QGraphicsScene`.
- Внутренние helpers можно назвать, например:
  - `_apply_angle_visibility(index: int)`;
  - `_apply_segment_visibility(index: int)`;
  - `_clear_hidden_angle_selection(index: int)`;
  - `_clear_hidden_segment_selection(index: int)`.

Где хранить состояние:
- Предпочтительно добавить поле `visible: bool = True` в canvas dataclasses:
  - `AngleMeasurement`;
  - `SegmentMeasurement`.
- Это поле должно жить только в canvas-слое.
- `angle_measurement_records(...)` и `segment_measurement_records(...)` не должны возвращать `visible`.
- `_store_current_angle_measurements()` и `_store_current_segment_measurements()` не должны переносить `visible` в проектную модель.
- `set_angle_measurement_records(...)` и `set_segment_measurement_records(...)` должны создавать загруженные измерения видимыми по умолчанию.
- `set_angle_measurements(...)` и `set_segment_measurements(...)` должны создавать новые измерения видимыми по умолчанию.
- `clear_angles()` и `clear_segments()` должны полностью сбрасывать canvas-состояние видимости вместе со списком измерений.

Важная деталь про существующую видимость graphics-item:
- Не все элементы всегда должны быть видимы даже при `visible=True`.
- Для угла:
  - линии, handles и label видимы, когда измерение visible;
  - arc видима только когда измерение visible и путь дуги не пустой.
- Для отрезка:
  - line, handles и length label видимы, когда измерение visible;
  - подпись первой точки видима только когда измерение visible и `start_label` не пустой;
  - подпись второй точки видима только когда измерение visible и `end_label` не пустой.
- Поэтому `_refresh_angle_graphic(...)`, `_refresh_segment_graphic(...)`, `_set_endpoint_label(...)` и любые новые helpers должны комбинировать новый флаг видимости с существующими условиями, а не просто делать всем элементам `setVisible(True)`.

Поведение углов:
- При `Показывать на канвасе = включено` у конкретного угла должны отображаться:
  - две линии угла;
  - дуга угла, если она рассчитана;
  - три draggable-точки;
  - подпись угла.
- При `Показывать на канвасе = выключено` у конкретного угла должны скрываться:
  - обе линии;
  - дуга;
  - все draggable-точки;
  - подпись.
- Скрытый угол должен оставаться доступным через:
  - `has_angle_measurements()`;
  - `angle_measurements()`;
  - `angle_measurement_records(...)`;
  - проектную модель `record.measurements.angles`.
- Если у скрываемого угла была выбрана вершина или другая handle-точка, выделение нужно сбросить.
- После скрытия выбранного угла команда `Удалить угол` не должна оставаться активной из-за скрытой selected-handle.
- При повторном включении угол должен появиться на прежнем месте с актуальным именем и значением.
- Изменение имени, примечания или геометрии скрытого угла не должно самопроизвольно показывать угол.
- Удаление другого угла не должно ломать fallback-нумерацию `Угол N` у видимых и скрытых углов.

Поведение отрезков:
- При `Показывать на канвасе = включено` у конкретного отрезка должны отображаться:
  - линия отрезка;
  - draggable-точки начала и конца;
  - подписи точек, если они заданы;
  - подпись имени и длины.
- При `Показывать на канвасе = выключено` у конкретного отрезка должны скрываться:
  - линия;
  - обе draggable-точки;
  - подписи точек;
  - подпись имени и длины.
- Скрытый отрезок должен оставаться доступным через:
  - `has_segment_measurements()`;
  - `segment_measurements()`;
  - `segment_measurement_records(...)`;
  - проектную модель `record.measurements.segments`.
- Если у скрываемого отрезка была выбрана endpoint-handle, выделение нужно сбросить.
- После скрытия выбранного отрезка команда `Удалить отрезок` не должна оставаться активной из-за скрытой selected-handle.
- При повторном включении отрезок должен появиться на прежнем месте с актуальным именем, длиной и подписями точек.
- Изменение имени, примечания, подписей точек, геометрии или калибровки скрытого отрезка не должно самопроизвольно показывать отрезок.
- Удаление другого отрезка не должно ломать fallback-нумерацию `Отрезок N` у видимых и скрытых отрезков.

Критерии приёмки:
- В свойствах каждого угла есть checkbox `Показывать на канвасе`.
- В свойствах каждого отрезка есть checkbox `Показывать на канвасе`.
- Пользователь может скрыть и снова показать отдельный угол.
- Пользователь может скрыть и снова показать отдельный отрезок.
- Скрытие угла скрывает все его canvas-элементы и не удаляет угол из проекта.
- Скрытие отрезка скрывает все его canvas-элементы и не удаляет отрезок из проекта.
- Скрытые измерения не появляются самопроизвольно после refresh/rebuild графики, движения handles, переименования, изменения подписей или пересчёта калибровки.
- Скрытие выбранного измерения сбрасывает selection и отключает соответствующую команду удаления.
- Visibility не сохраняется в JSON проекта и не запускает autosave.
- Создание, удаление, переименование, редактирование примечаний, подписи точек, переключение изображений, калибровка и существующие сценарии измерений продолжают работать.
- Существующие тесты проходят; добавлены тесты для видимости углов и отрезков.
