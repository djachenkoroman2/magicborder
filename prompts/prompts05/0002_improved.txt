Задача: добавить в панель "Свойства изображения" группу вычисляемых свойств "Цветовое пространство Lab".

Контекст:
- В интерфейсе есть панель "Свойства изображения" с группами свойств выбранного изображения.
- В панели уже есть группа "Цветовое пространство RGB", где отображаются вычисляемые значения по текущему контуру изображения.
- Нужно добавить новую группу "Цветовое пространство Lab" сразу после группы "Цветовое пространство RGB".
- Значения Lab должны вычисляться по аналогии с RGB и не должны сохраняться в JSON проекта.

Область изменений:
- Панель "Свойства изображения".
- Логика вычисления статистики по пикселям внутри текущего контура.
- Экспорт свойств изображения в Excel, если он использует список групп и свойств панели.
- Тесты, проверяющие порядок групп, вычисляемые значения и экспорт свойств изображения.

Требования к интерфейсу:
- Добавить группу "Цветовое пространство Lab" сразу после группы "Цветовое пространство RGB" и перед следующими существующими группами.
- В группе должны быть свойства:
  - "L".
  - "a".
  - "b".
- Свойства должны быть read-only, так как они вычисляются автоматически.
- Группа должна вести себя так же, как остальные группы панели: отображаться в property browser, сворачиваться/разворачиваться и сохранять общий визуальный стиль интерфейса.
- Если изображение не выбрано, контур отсутствует, файл изображения недоступен или значения невозможно вычислить, показывать пустое состояние в стиле существующих вычисляемых свойств, например "-".

Требования к вычислениям:
- Рассчитывать Lab по пикселям внутри текущего контура выбранного изображения.
- Использовать тот же набор пикселей, который применяется для вычисления средних RGB-значений и количества пикселов контура.
- Преобразование RGB -> Lab выполнять через существующий стек проекта, предпочтительно `OpenCV`, если он уже используется для цветовых преобразований.
- Не пересчитывать маску контура лишний раз, если текущая логика уже получает массив RGB-пикселей внутри контура.
- Средние значения L, a и b должны обновляться при:
  - выборе другого изображения;
  - загрузке проекта;
  - создании, изменении или удалении контура;
  - изменении выбранного изображения или его аннотации.
- Формат значений должен быть согласован с текущим отображением RGB: компактные числовые строки без лишних пояснений.
- Если в проекте уже принят конкретный диапазон Lab из OpenCV, использовать его последовательно. Если нужно показывать человеку привычные значения, явно нормализовать и покрыть это тестами.

Требования к данным и JSON:
- Не добавлять Lab-значения в JSON проекта, так как это вычисляемые свойства.
- Не менять формат существующих записей изображений, групп `file`, `contour`, `location`, `details` и данных аннотаций.
- Открытие старых проектов должно работать без миграции.
- Сохранение проекта после просмотра Lab-свойств не должно создавать новых полей только из-за вычислений.

Требования к экспорту:
- Если экспорт свойств изображения в Excel строится из общего списка групп панели, добавить свойства "L", "a" и "b" в соответствующую группу "Цветовое пространство Lab".
- В диалоге выбора свойств для экспорта новая группа и её свойства должны отображаться в ожидаемом порядке.
- В Excel значения Lab должны попадать в экспорт так же, как RGB-значения.
- При отсутствии контура или невозможности вычисления значения экспорт должен использовать то же пустое значение, которое отображается в интерфейсе.

Рекомендации по реализации:
- Расширить существующую структуру описания групп свойств изображения, если она уже используется для UI и экспорта.
- Вынести вычисление средних Lab в небольшой helper рядом с существующей логикой вычисления RGB, чтобы не дублировать обход пикселей и обработку пустых состояний.
- Для OpenCV учитывать порядок каналов: если исходные пиксели хранятся как RGB, перед `cv2.cvtColor` использовать корректный код преобразования, например `cv2.COLOR_RGB2LAB`.
- При программном обновлении значений не запускать обработчики редактируемых полей.
- Не менять логику проекта, контуров, гистограмм, меню, тулбара, списка изображений и сохранения, кроме прямой необходимости для нового свойства.

Критерии приемки:
- В панели "Свойства изображения" появилась группа "Цветовое пространство Lab" сразу после "Цветовое пространство RGB".
- В группе отображаются read-only свойства "L", "a" и "b".
- Для изображения с корректным контуром значения Lab вычисляются по пикселям внутри контура.
- При изменении контура значения Lab обновляются без перезапуска приложения.
- При отсутствии контура, файла или выбранного изображения интерфейс не падает и показывает ожидаемое пустое состояние.
- Lab-значения не сохраняются в JSON проекта.
- Экспорт свойств изображения в Excel включает Lab-свойства, если пользователь выбирает их для экспорта.
- Существующие RGB-свойства, средний цвет, метаданные, ID, переименование файла, выбор даты/времени и экспорт продолжают работать как раньше.
- Существующие тесты проходят; добавлены или обновлены тесты на порядок группы Lab, корректное вычисление значений, пустое состояние и отсутствие Lab-полей в JSON.
