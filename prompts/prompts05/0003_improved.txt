Задача: добавить в панель "Свойства проекта" группу вычисляемых свойств "Цветовое пространство Lab".

Контекст:
- В интерфейсе есть панель "Свойства проекта".
- В этой панели уже есть группа "Цветовое пространство RGB" с вычисляемыми средними значениями R, G и B по проекту.
- Нужно добавить новую группу "Цветовое пространство Lab" сразу после группы "Цветовое пространство RGB".
- Значения Lab должны вычисляться по аналогии с проектными RGB-значениями и не должны сохраняться в JSON проекта.

Область изменений:
- Панель "Свойства проекта".
- Логика вычисления сводных цветовых характеристик проекта.
- Общие helper'ы расчёта цветовых значений, если они уже используются для RGB или Lab в свойствах изображения.
- Тесты, проверяющие порядок групп, вычисляемые значения и отсутствие новых полей в JSON.

Требования к интерфейсу:
- Добавить группу "Цветовое пространство Lab" сразу после группы "Цветовое пространство RGB".
- В группе должны быть read-only свойства:
  - "Средний L".
  - "Средний a".
  - "Средний b".
- Группа должна отображаться и вести себя так же, как остальные группы панели "Свойства проекта": использовать текущий property browser, поддерживать сворачивание/разворачивание и общий визуальный стиль.
- Если проект не открыт или данных для расчёта нет, показывать пустое состояние в стиле существующих вычисляемых свойств, например "-".

Требования к вычислениям:
- Рассчитывать средние Lab-значения по пикселям внутри контуров всех изображений проекта.
- Использовать те же правила отбора изображений, которые применяются для проектных средних RGB:
  - учитывать только изображения с существующим и корректно загружаемым файлом;
  - учитывать только изображения с корректной аннотацией контура;
  - пропускать изображения без контура, с повреждённой аннотацией, отсутствующим файлом, несовпадающим размером аннотации или пустой областью внутри контура.
- Использовать тот же набор пикселей, который участвует в расчёте проектных средних RGB, чтобы Lab и RGB описывали одну и ту же совокупность данных.
- Преобразование RGB -> Lab выполнять через существующий стек проекта, предпочтительно `OpenCV`, если он уже используется для цветовых преобразований.
- Если в проекте уже есть helper для расчёта Lab в свойствах изображения, переиспользовать его или вынести общий helper, чтобы не дублировать формулу.
- Использовать ту же шкалу Lab, которая применяется в других частях приложения, например в Lab-гистограмме или свойствах изображения:
  - `L` в диапазоне 0..100;
  - `a` и `b` со сдвигом относительно OpenCV-значений, обычно в диапазоне примерно -128..127.
- Формат отображения должен быть компактным и согласованным с проектными RGB-свойствами: числовые строки без лишних пояснений.

Требования к обновлению значений:
- Значения Lab должны обновляться при:
  - открытии проекта;
  - создании нового проекта;
  - добавлении, удалении или синхронизации изображений;
  - выборе изображения, если это влияет на загрузку или актуализацию аннотации;
  - создании, изменении или удалении контура;
  - изменении состава проекта или аннотаций.
- Обновление Lab не должно раскрывать группы самопроизвольно и не должно запускать лишнее сохранение проекта.

Требования к данным и JSON:
- Не добавлять значения "Средний L", "Средний a" и "Средний b" в JSON проекта.
- Не менять формат проекта, записи изображений, аннотации и существующие группы `file`, `contour`, `location`, `details`.
- Открытие старых проектов должно работать без миграции.
- Сохранение проекта после просмотра Lab-свойств не должно создавать новых полей только из-за вычислений.

Рекомендации по реализации:
- Расширить текущую логику `_project_contours_mean_rgb` или вынести общий helper, который считает средние значения по всем пикселям контуров проекта.
- Не выполнять лишнее чтение изображений и построение масок, если RGB и Lab можно вычислить за один проход по тем же пикселям.
- Для OpenCV учитывать порядок каналов: если массив пикселей хранится как RGB, использовать `cv2.COLOR_RGB2LAB`.
- При отсутствии данных возвращать `None` или другое уже принятое пустое состояние, а в UI показывать "-".
- Не менять логику панели "Свойства изображения", экспорта Excel, гистограмм, списка изображений, канваса, меню и тулбара, кроме случаев, когда общий helper действительно должен быть переиспользован.

Критерии приемки:
- В панели "Свойства проекта" появилась группа "Цветовое пространство Lab" сразу после "Цветовое пространство RGB".
- В группе отображаются свойства "Средний L", "Средний a" и "Средний b".
- Для проекта с несколькими изображениями и корректными контурами значения Lab считаются по пикселям внутри всех доступных контуров.
- Изображения без контура, с отсутствующим файлом или некорректной аннотацией не ломают расчёт и пропускаются.
- При отсутствии подходящих данных отображается "-".
- При изменении контура или состава проекта значения Lab обновляются без перезапуска приложения.
- Lab-значения не сохраняются в JSON проекта.
- Существующие проектные RGB-свойства, "Общая информация", количество изображений, свойства изображения, экспорт и сохранение проекта продолжают работать как раньше.
- Существующие тесты проходят; добавлены или обновлены тесты на порядок группы Lab, корректное вычисление проектных Lab-значений, пустое состояние и отсутствие Lab-полей в JSON.
