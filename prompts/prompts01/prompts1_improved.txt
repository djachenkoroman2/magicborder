Разработай полноценное настольное приложение на Python для локальной работы с фотографиями листьев растений. Приложение должно автоматически определять границу листа на изображении и представлять её в виде одного редактируемого замкнутого контура.

Используй следующий стек и ограничения:
- язык программирования: Python;
- локальное окружение и управление зависимостями: `uv`;
- графический интерфейс: `PyQt5`;
- приложение должно быть рассчитано на локальный запуск пользователем на desktop-платформе.

Функциональные требования:
1. Пользователь должен иметь возможность открыть изображение листа растения из файла.
2. Необходимо поддержать загрузку распространённых растровых форматов, например: `png`, `jpg`, `jpeg`, `bmp`, `tif`, `tiff`.
3. После загрузки изображение должно отображаться на канвасе.
4. Для изображения на канвасе должны быть реализованы команды масштабирования и просмотра:
   - увеличить;
   - уменьшить;
   - показать целиком;
   - вернуть масштаб 100%.
5. Для одного изображения должен поддерживаться только один контур.
6. Команда `Определить контур` должна автоматически находить границу листа растения на изображении и строить по ней замкнутый контур.
7. Контур должен быть представлен как замкнутая кривая, состоящая из узлов и соединяющих их сегментов.
8. После автоматического построения пользователь должен иметь возможность редактировать контур вручную:
   - перемещать существующие узлы мышью по канвасу;
   - добавлять новые узлы;
   - удалять существующие узлы.
9. Контур должен визуально отображаться поверх изображения.

Требования к интерфейсу:
1. В приложении должны быть реализованы главное окно, меню и панель инструментов.
2. Меню должно содержать группы:
   - `Файл (File)`;
   - `Вид (View)`;
   - `Инструменты (Tools)`;
   - `Помощь (Help)`.
3. В меню `Файл (File)` должны быть команды:
   - `Открыть изображение (Open)`;
   - `Сохранить изображение (Save)`;
   - `Выход (Exit)`.
4. В меню `Вид (View)` должны быть все команды, связанные с отображением изображения и масштабированием.
5. В меню `Инструменты (Tools)` должны быть команды:
   - `Определить контур` — автоматическое выделение границы листа и создание контура;
   - `Сохранить аннотацию` — сохранение текущего редактируемого контура в файл `json`;
   - `Открыть аннотацию` — загрузка контура из файла `json` с последующим редактированием на канвасе.
6. В меню `Помощь (Help)` должна быть команда `О программе`, открывающая диалоговое окно с краткой информацией о приложении.

Требования к сохранению данных:
1. Аннотация должна сохраняться в формате `json`.
2. В `json` должны храниться как минимум:
   - путь или имя исходного изображения;
   - размеры изображения;
   - список точек контура в порядке обхода;
   - признак замкнутости контура.
3. При загрузке аннотации контур должен корректно восстанавливаться на канвасе и оставаться редактируемым.

Требования к реализации:
1. Организуй проект в виде понятной модульной структуры.
2. Выдели отдельно:
   - логику GUI;
   - работу с изображением и канвасом;
   - алгоритм автоматического определения контура;
   - модели данных аннотации;
   - сохранение и загрузку `json`.
3. Предусмотри обработку типовых ошибок:
   - попытка открыть неподдерживаемый файл;
   - попытка сохранить аннотацию при отсутствии контура;
   - попытка загрузить повреждённый или некорректный `json`.
4. Код должен быть читаемым, расширяемым и пригодным для дальнейшего улучшения алгоритма сегментации.

Ожидаемый результат:
1. Полный исходный код проекта.
2. Файл `pyproject.toml` для работы через `uv`.
3. Инструкция по запуску проекта.
4. Краткое описание архитектуры.
5. Рабочий GUI, в котором можно:
   - открыть изображение;
   - отмасштабировать его на канвасе;
   - автоматически построить один замкнутый контур листа;
   - отредактировать узлы контура;
   - сохранить и загрузить аннотацию в `json`.

Если в ходе реализации придётся принять технические решения, выбирай практичные и простые в сопровождении варианты. Сначала реализуй стабильный MVP с понятной архитектурой, затем дополнительные улучшения. В ответе покажи структуру проекта, ключевые файлы и полный код.
