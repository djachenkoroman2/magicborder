Доработай интерфейс приложения и поведение имён файлов.

Нужно реализовать четыре связанные доработки:

1. Команда сброса интерфейса к виду по умолчанию.
2. Отображение имени открытого изображения в заголовке окна.
3. Более удобное имя по умолчанию при сохранении аннотации.
4. Более удобные имена по умолчанию при сохранении гистограмм.

Команда "Вид по умолчанию":
   - В меню "Вид" добавь новую команду "Вид по умолчанию".
   - Команда должна возвращать интерфейс к стандартному состоянию:
     - левая область изображения и правая область аналитики возвращаются к исходному соотношению 4:1;
     - высоты подпанелей гистограмм в правой панели возвращаются к равномерному или проектному значению по умолчанию;
     - изображение снова вписывается в левую область просмотра, если изображение загружено;
     - другие параметры вида, которые уже есть в проекте и логически относятся к раскладке интерфейса, также возвращаются к значениям по умолчанию.
   - Команда не должна удалять загруженное изображение, контур, аннотацию или рассчитанные гистограммы.
   - Команда должна быть доступна в меню "Вид".
   - Команда должна быть добавлена на основную панель инструментов.
   - Для команды нужно разработать SVG-иконку в стиле существующих иконок проекта.
   - Иконку нужно поместить в папку с иконками приложения и подключить через существующий механизм иконок.
   - Для команды должны быть русские tooltip/status tip.
   - Если в проекте уже есть соглашение о горячих клавишах, можно добавить подходящий shortcut, например `Ctrl+R` или другой свободный вариант.

Заголовок окна:
   - После открытия изображения в заголовке главного окна должно отображаться имя открытого файла.
   - Формат заголовка должен быть понятным, например:
     - `MagicBorder - leaf.png`
   - Если изображение не открыто, заголовок должен оставаться базовым:
     - `MagicBorder`
   - При открытии другого изображения заголовок должен обновляться.
   - Если при загрузке аннотации приложение автоматически открывает связанное изображение, заголовок также должен обновиться.

Имя по умолчанию для сохранения аннотации:
   - При сохранении аннотации имя файла, предложенное в диалоге сохранения, должно совпадать с именем текущего открытого изображения без расширения.
   - Расширение для аннотации должно быть `.json`.
   - Например:
     - открыто изображение `leaf_photo.jpg`;
     - в диалоге сохранения аннотации предлагается `leaf_photo.json`.
   - Если текущая аннотация уже была сохранена ранее и приложение хранит её путь, можно предлагать существующий путь аннотации, чтобы не ломать привычный сценарий повторного сохранения.
   - Если изображение не открыто, используй безопасное имя по умолчанию, например `annotation.json`.

Имена по умолчанию для сохранения гистограмм:
   - При сохранении любой гистограммы имя файла по умолчанию должно начинаться с имени текущего открытого изображения без расширения.
   - После префикса нужно добавлять суффикс цветового пространства.
   - Примеры для изображения `leaf_photo.jpg`:
     - `leaf_photo_rgb_histogram.png`;
     - `leaf_photo_lab_histogram.png`;
     - `leaf_photo_hsv_histogram.png`;
     - `leaf_photo_yuv_histogram.png`;
     - `leaf_photo_lms_histogram.png`.
   - Если изображение не открыто, должны использоваться текущие безопасные имена по умолчанию, например:
     - `rgb_histogram.png`;
     - `lab_histogram.png`;
     - `hsv_histogram.png`.
   - Логика должна работать для всех уже реализованных гистограмм.
   - Сохраняемый файл должен оставаться PNG.
   - Если пользователь ввёл имя без расширения, приложение должно добавить `.png`.

Требования к реализации:
   - Используй существующие классы, сигналы, QAction, QSplitter и механизм подключения иконок.
   - Не дублируй логику получения имени текущего изображения: лучше вынести небольшой helper, если это упростит код.
   - Не ломай существующие команды открытия изображения, сохранения изображения, сохранения/загрузки аннотаций, редактирования контура и сохранения гистограмм.
   - Не меняй формат JSON-аннотации.
   - Не меняй алгоритмы расчёта гистограмм.

Критерии готовности:
   - В меню "Вид" появилась команда "Вид по умолчанию".
   - Эта команда есть на панели инструментов и имеет SVG-иконку.
   - После изменения размеров панелей команда возвращает соотношение областей и подпанелей к значениям по умолчанию.
   - После открытия изображения имя файла отображается в заголовке окна.
   - При открытии другого изображения заголовок обновляется.
   - При сохранении аннотации для изображения `example.png` предлагается имя `example.json`.
   - При сохранении RGB-гистограммы для изображения `example.png` предлагается имя `example_rgb_histogram.png`.
   - Аналогичные имена предлагаются для Lab, HSV, YUV и LMS-гистограмм.
   - Все существующие функции приложения продолжают работать.
