Доработай интерфейс приложения для анализа изображения внутри основного контура.

Нужно разделить рабочее пространство на две основные области:

1. Левая область - панель просмотра изображения.
   - В ней отображается загруженное и обрабатываемое изображение.
   - На изображении должен отображаться основной контур, которым пользователь ограничивает анализируемую область.
   - Существующее поведение контура и его узлов нужно сохранить.

2. Правая область - панель свойств и аналитики.
   - Она располагается справа от изображения.
   - По умолчанию соотношение ширины левой и правой областей должно быть 4:1.
   - Вертикальный разделитель между левой и правой областями должен перетаскиваться мышью.
   - При изменении ширины областей содержимое панелей должно корректно адаптироваться без наложений и выхода за границы.

В правой области нужно добавить две вертикально расположенные подпанели с гистограммами.

Первая подпанель: RGB-гистограмма.
   - В подпанели должен быть canvas для отображения гистограммы пикселей изображения, попавших внутрь основного контура.
   - Гистограмма строится в цветовом пространстве RGB.
   - Все три канала R, G и B должны отображаться на одном графике.
   - Используй 256 bins для диапазона значений 0..255.
   - Каналы должны визуально различаться цветами:
     - R - красный;
     - G - зелёный;
     - B - синий.
   - У графика должны быть понятные оси, сетка или деления, легенда каналов и подпись диапазона значений.
   - Если контур ещё не создан или внутри контура нет пикселей, вместо графика нужно показать аккуратное пустое состояние.
   - В панели должна быть команда сохранения гистограммы на диск.
   - Сохранение должно экспортировать текущий вид RGB-гистограммы в файл изображения, например PNG.

Вторая подпанель: Lab-гистограмма.
   - Она располагается ниже RGB-гистограммы.
   - Размер подпанели должен изменяться по вертикали с помощью горизонтального перетаскиваемого разделителя.
   - В подпанели должен быть canvas для отображения гистограммы пикселей изображения, попавших внутрь основного контура.
   - Гистограмма строится в цветовом пространстве Lab.
   - Все три канала L, a и b должны отображаться на одном графике.
   - Для преобразования RGB -> Lab используй корректную формулу CIE Lab или уже существующую библиотечную функцию, если она есть в проекте.
   - Для канала L учитывай диапазон светлоты 0..100.
   - Для каналов a и b учитывай их реальный знаковый диапазон. При отрисовке можно привести значения к удобной шкале, но подписи на графике должны оставаться понятными.
   - Каналы должны визуально различаться:
     - L - нейтральный серый или белый;
     - a - зелёный/пурпурный акцент;
     - b - синий/жёлтый акцент.
   - У графика должны быть понятные оси, сетка или деления, легенда каналов и подпись диапазона значений.
   - Если контур ещё не создан или внутри контура нет пикселей, вместо графика нужно показать аккуратное пустое состояние.
   - В панели должна быть команда сохранения гистограммы на диск.
   - Сохранение должно экспортировать текущий вид Lab-гистограммы в файл изображения, например PNG.

Пересчёт гистограмм:
   - RGB- и Lab-гистограммы должны строиться автоматически после создания основного контура.
   - Обе гистограммы должны пересчитываться и перерисовываться при любом изменении контура:
     - перемещение узлов;
     - добавление узлов;
     - удаление узлов;
     - перемещение всего контура, если такая команда есть;
     - изменение изображения, если пользователь загрузил новое изображение.
   - Пересчёт должен выполняться только по пикселям, находящимся внутри основного контура.
   - Пиксели за пределами контура не должны попадать в расчёт.
   - Если контур частично выходит за границы изображения, расчёт должен учитывать только существующие пиксели изображения.
   - При интерактивном перетаскивании узлов обновление должно быть достаточно плавным. При необходимости используй debounce/throttle или requestAnimationFrame, чтобы интерфейс не зависал.

Поведение интерфейса:
   - Правая панель должна оставаться пригодной для дальнейшего добавления новых панелей свойств.
   - Подпанели гистограмм должны иметь заголовки, кнопки сохранения и устойчивую адаптивную верстку.
   - Кнопки сохранения должны иметь русские всплывающие подсказки.
   - Если в проекте уже есть общий стиль кнопок, иконок, панелей или разделителей, используй его.
   - Не ломай существующие команды загрузки, отображения, редактирования контура и сохранения изображения.

Критерии готовности:
   - После загрузки изображения и создания основного контура в правой панели автоматически появляются RGB- и Lab-гистограммы.
   - При изменении формы контура обе гистограммы обновляются.
   - Вертикальный разделитель между изображением и правой панелью работает, стартовое соотношение областей близко к 4:1.
   - Горизонтальный разделитель между подпанелями гистограмм работает.
   - Каждую гистограмму можно сохранить на диск отдельной командой.
   - Сохранённые изображения гистограмм соответствуют тому, что пользователь видит в canvas.
   - Интерфейс не содержит наложений текста, кнопок и canvas при обычных размерах окна.
