Доработай окно свойств изображения: добавь рядом с редактируемым полем `ID` кнопку автоматической генерации пользовательского ID.

Главная цель:
   - В окне свойств выбранного изображения рядом с полем `ID` должна появиться отдельная кнопка генерации ID.
   - Кнопка должна генерировать новый пользовательский ID только по явному действию пользователя.
   - Сгенерированный ID должен соответствовать существующим правилам генерации ID в проекте.
   - Сгенерированный ID должен сразу записываться в текущую запись изображения, отображаться в поле `ID` и сохраняться в JSON проекта.

Контекст текущей модели:
   - Пользовательский ID изображения хранится отдельно от технического `record.id`.
   - Используй `metadata.sample_id` как пользовательский ID.
   - Не смешивай пользовательский `ID` с внутренним техническим `id` записи.
   - Технический `record.id` нужен для выбора записи, списка и стабильной работы проекта.
   - Пользовательский `metadata.sample_id` нужен для пользователя, CSV-экспорта и переименования файла по ID.
   - Старые проекты без `metadata.sample_id` должны продолжить открываться без ошибок.

Поведение генерации:
   - Используй существующую логику генерации уникального ID, если она уже есть в проекте.
   - В текущей архитектуре ориентируйся на helper `_unique_project_sample_id(...)`.
   - Базовое значение для генерации бери из имени файла без расширения.
   - Если имя файла пустое или недоступно, используй безопасную базу вроде `image`.
   - Если базовый ID уже занят другим изображением проекта, генератор должен добавить числовой суффикс по существующему правилу проекта, например:
     - `leaf`;
     - `leaf_1`;
     - `leaf_2`.
   - Новый ID должен быть уникален среди всех изображений текущего проекта.
   - Проверка уникальности должна учитывать все записи проекта, кроме текущей.
   - Не перегенерируй ID автоматически при выборе изображения, открытии проекта, обновлении свойств или редактировании других метаданных.
   - Не меняй ID существующих изображений без явного нажатия кнопки генерации.

Поведение при нажатии кнопки:
   - Если проект не открыт или изображение не выбрано, кнопка должна быть недоступна.
   - При нажатии кнопки сгенерируй ID для текущего изображения.
   - Запиши значение через тот же путь сохранения и валидации, который используется при ручном редактировании `metadata.sample_id`.
   - После успешной генерации обнови поле `ID` в интерфейсе.
   - После успешной генерации запланируй или выполни сохранение проекта через существующий механизм.
   - Если генерация по какой-то причине дала некорректный ID, покажи понятное предупреждение на русском языке и не меняй старое значение.
   - Если сгенерированный ID совпал с текущим ID, не показывай ошибку; можно оставить значение как есть и при необходимости вывести короткое сообщение в status bar.

Интерфейс:
   - Поле `ID` должно остаться редактируемым.
   - Кнопка генерации должна находиться в той же строке формы, что и поле `ID`.
   - Оберни поле `ID` и кнопку в небольшой горизонтальный контейнер, как уже сделано для имени файла или полей даты/времени.
   - Не путай новую кнопку генерации ID с существующей кнопкой `Переименовать файл как ID` в строке `Файл`.
   - Существующая кнопка переименования файла по ID должна продолжить работать без изменений.
   - Для новой кнопки добавь tooltip на русском языке, например `Сгенерировать ID`.
   - Добавь status tip на русском языке, например `Сгенерировать уникальный ID изображения по правилам проекта.`
   - Если в проекте используется система SVG-иконок, добавь отдельную иконку в стиле текущих иконок проекта.
   - Если подходящей иконки нет, можно использовать короткий текст на кнопке, но предпочтительно сделать SVG-иконку.
   - Размеры и отступы кнопки должны совпадать с существующими маленькими кнопками в панели свойств.

Валидация и сохранение:
   - Используй существующую проверку ID:
     - ID не должен быть пустым;
     - ID должен быть уникальным внутри проекта;
     - пробелы по краям нужно обрезать.
   - Не дублируй логику валидации, если её можно переиспользовать.
   - После генерации ID должен сохраняться в `metadata.sample_id` текущей записи.
   - После закрытия и повторного открытия проекта сгенерированный ID должен восстановиться из JSON.
   - CSV-экспорт должен использовать новый ID так же, как ID, введённый вручную.
   - Кнопка `Обновить свойства` не должна стирать или перегенерировать ID.
   - Переименование файла, удаление контура и редактирование других метаданных не должны менять ID автоматически.

Совместимость:
   - Не ломай существующий формат JSON проекта.
   - Не ломай открытие старых проектов.
   - Не ломай добавление изображений в проект.
   - Не ломай ручное редактирование ID.
   - Не ломай проверку уникальности ID.
   - Не ломай экспорт CSV.
   - Не ломай кнопку переименования файла как ID.
   - Все новые пользовательские сообщения должны быть на русском языке.
   - Код должен соответствовать текущей архитектуре PyQt5-приложения.

Критерии готовности:
   - В строке `ID` окна свойств есть кнопка генерации ID.
   - Кнопка недоступна, если нет выбранного изображения.
   - При нажатии кнопки в поле `ID` появляется уникальный ID.
   - Новый ID строится от имени файла без расширения и использует существующие правила разрешения конфликтов.
   - Если ID `leaf` уже занят, следующее изображение получает свободный вариант вроде `leaf_1`.
   - Сгенерированный ID сохраняется в `metadata.sample_id`.
   - После сохранения, закрытия и повторного открытия проекта ID остаётся прежним.
   - Ручное редактирование ID продолжает работать.
   - Дублирующийся ID по-прежнему нельзя сохранить вручную.
   - CSV-экспорт содержит сгенерированный ID.
   - Существующая кнопка `Переименовать файл как ID` продолжает переименовывать файл по текущему ID.
   - Автоматического изменения ID без нажатия новой кнопки не происходит.

Тесты:
   - Добавь или обнови тесты для генерации ID в окне свойств.
   - Проверь, что кнопка имеет русские tooltip/status tip и включается только при выбранном изображении.
   - Проверь генерацию ID для изображения с именем файла `leaf.png`.
   - Проверь генерацию ID при конфликте с уже существующим `metadata.sample_id`.
   - Проверь, что сгенерированный ID сохраняется в JSON проекта.
   - Проверь, что ручное редактирование ID и проверка уникальности не сломались.
