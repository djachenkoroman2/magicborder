Сделай проект который должен выделять границы листа растения по фотографии в виде замкнутого контура (предусмотреть загрузку файлов разных растровых форматов).
Изображение должно быть помещено на канвасе. Также должно быть предусмотрена возможность масштабирования изображения на канвасе при помощи команд
Замкнутый контур листа должен представлять собой замкнутую кривую состоящую из узлов и линий между ними. Предполагается, что после автоматического выделения контура пользователю предоставится возможность редактировать положение узлов (перемещение по канвасу). Также пользоваттелю должна быть предоставлена возможность добавлять дополнительные узлы в контур а также удалять их.
Язык программирования python. Локальное окружение uv.
Графический интерфейс необходимо разработать в PyQt5.
Предусмотреть меню и панель инструментов.
Группы команд меню "Файл" (File), "Вид" (View), "Инструменты" (Tools) и "Помощь" (Help).
В группе команд "Файл" предусмотреть команды Открыть изображение (Open), Сохранить изображение (Save), Выход из программы (Exit)
В группе команд "Вид" предусмотреть все команды для отображения изображения.
В группе команд "Инструменты" создать команду "Определить контур" которая должна выделить границы листа растения и создать контур. Также необходимо создать команду, которая сохраняет текущий редактируемый контур (аннотацию к изображению) в формате json. Также необходимо создать команду которая открывает файл с аннотацией в формате json и загружает контур в канвас с возможностью его редактирования.
На одно изображение предусмотреть только один контур.
В группе команд "Помощь" предусмотреть команды которая выводит диалог О программе.
