Задача: доработать панель `Свойства проекта` в MagicBorder, добавив в нее имя проекта и путь к файлу проекта.

Исходная формулировка:
"В панель Свойства проекта необходимо внести информацию:
В группу Общие свойства перед Общей информацией необходимо добавить свойства: Имя проекта (указывается без расширения json, редактируемое свойство), Путь (путь к файлу с проектом, read only)"

Контекст проекта:
- MagicBorder - настольное приложение на Python и `PyQt5`.
- Панель проекта реализована в `src/magicborder/main_window.py`.
- В левой панели уже есть блок `Свойства проекта`, созданный методом `_create_project_properties_panel`.
- Свойства отображаются через `PropertyBrowser` из `src/magicborder/property_browser.py`.
- В группе `Общие свойства` сейчас есть:
  - `Общая информация`;
  - `Количество изображений`.
- Модель проекта описана в `src/magicborder/models.py`.
- Имя проекта уже хранится в `ProjectDocument.name`.
- Путь к открытому проекту хранится в `MainWindow.project_path`.
- Сохранение проекта выполняется через `_schedule_project_save()` / `_save_project_silently()`.
- Заголовок окна обновляется через `_update_window_title()`.

Цель:
- В панели `Свойства проекта` в группе `Общие свойства` показать две новые строки перед `Общая информация`:
  1. `Имя проекта` - редактируемое значение;
  2. `Путь` - путь к JSON-файлу проекта, только для чтения.
- Не менять структуру панели изображений и панель свойств изображения.
- Не добавлять отдельные диалоги, меню или новые команды: работа должна происходить прямо в существующей панели свойств проекта.

Ожидаемый порядок строк в группе `Общие свойства`:
```text
--- Общие свойства
Имя проекта
Путь
Общая информация
Количество изображений
```

Поведение поля `Имя проекта`:
- Использовать редактируемое поле, подходящее существующему стилю панели, например `QLineEdit`.
- Значение брать из `self.project_document.name`.
- Показывать имя без расширения `.json`.
- Если пользователь ввел имя с расширением `.json`, аккуратно убрать только это расширение.
- При редактировании:
  - обрезать пробелы по краям;
  - не принимать пустое имя;
  - не принимать путь вместо имени, то есть значения с `/` или `\`;
  - при некорректном значении показать понятное предупреждение и вернуть предыдущее имя;
  - при корректном значении обновить `self.project_document.name`;
  - запланировать сохранение проекта через `_schedule_project_save()`;
  - обновить заголовок окна через `_update_window_title()`.
- Изменение `Имя проекта` не должно переименовывать JSON-файл проекта, папку проекта или менять `self.project_path`. Это только редактирование имени внутри документа проекта.

Поведение поля `Путь`:
- Поле должно быть read only.
- Показывать полный путь к JSON-файлу проекта из `self.project_path`.
- Если проект не открыт, поле должно очищаться или показывать `-` вместе с остальными проектными свойствами.
- Значение должно быть доступно для выделения/копирования пользователем.
- Редактирование пользователем запрещено.

Состояния UI:
- Когда проект не открыт:
  - блок `Свойства проекта` должен вести себя как сейчас: показывать сообщение `Создайте или откройте проект.`;
  - новые поля должны быть очищены или переведены в безопасное значение `-`;
  - редактирование имени проекта должно быть недоступно.
- Когда проект создан или открыт:
  - `Имя проекта` сразу показывает актуальное имя;
  - `Путь` сразу показывает путь к открытому JSON-файлу;
  - `Общая информация`, `Количество изображений` и цветовые агрегаты продолжают обновляться как раньше.
- При создании нового проекта имя в панели должно совпадать с именем `ProjectDocument.name`.
- При открытии старого проекта без явного имени использовать существующую модельную логику `ProjectDocument.from_dict`, не ломая обратную совместимость.

Ограничения:
- Не менять формат JSON проекта, кроме уже существующего поля `name`.
- Не добавлять новое поле пути в JSON проекта: путь является runtime-состоянием окна, а не данными проекта.
- Не переименовывать файл проекта автоматически.
- Не менять поведение поля `Общая информация`.
- Не менять экспорт свойств изображения и экспорт списка проекта, если это не требуется для прохождения существующих тестов.
- Не ломать существующие тесты и сценарии создания/открытия/сохранения проекта.
- Не добавлять новые зависимости.

Рекомендуемые места изменений:
- `src/magicborder/main_window.py`:
  - добавить widgets для `Имя проекта` и `Путь` в `_create_project_properties_panel`;
  - вставить новые свойства в группу `Общие свойства` перед `Общая информация`;
  - обновлять значения в `_update_project_summary_properties`;
  - добавить обработчик завершения редактирования имени проекта;
  - при успешном изменении имени вызывать `_schedule_project_save()` и `_update_window_title()`.
- `tests/test_project_properties.py`:
  - обновить тест порядка строк панели `Свойства проекта`;
  - добавить проверку, что `Путь` read only;
  - добавить проверку, что имя проекта отображается без `.json`;
  - добавить проверку, что редактирование имени обновляет `ProjectDocument.name` и сохраняется в JSON;
  - добавить проверку, что редактирование имени не меняет `project_path`.

Рекомендуемые тестовые сценарии:
1. Панель `Свойства проекта` содержит строки в ожидаемом порядке:
   - `Имя проекта`;
   - `Путь`;
   - `Общая информация`;
   - `Количество изображений`.
2. После открытия проекта `Имя проекта` равно `project_document.name`, а `Путь` равен `str(project_path)`.
3. Поле `Путь` имеет режим read only.
4. После редактирования `Имя проекта`:
   - `window.project_document.name` обновлен;
   - JSON проекта после сохранения содержит новое поле `name`;
   - `window.project_path` остался прежним;
   - заголовок окна обновился.
5. Если пользователь вводит `NewName.json`, в `ProjectDocument.name` сохраняется `NewName`.
6. Если пользователь вводит пустую строку или путь, значение отклоняется и возвращается предыдущее имя.

Проверки перед завершением:
- `uv run pytest`
- Если менялись только UI-тесты и логика панели, отдельная portable-сборка не требуется.

Критерии готовности:
- В `Свойства проекта -> Общие свойства` появились `Имя проекта` и `Путь` перед `Общая информация`.
- `Имя проекта` редактируется и сохраняется в существующее поле `ProjectDocument.name`.
- `Путь` отображает файл проекта и не редактируется.
- Существующее поведение `Общая информация`, количества изображений и цветовых сводок сохранено.
- Все тесты проходят.
