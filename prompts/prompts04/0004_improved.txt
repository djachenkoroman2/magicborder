Задача: добавить в графический интерфейс возможность сворачивать и разворачивать группы в панелях.

Контекст:
- В интерфейсе есть панели со сгруппированными элементами, например "Свойства проекта" и "Свойства изображения".
- Сейчас группы отображаются всегда раскрытыми.
- Нужно сделать группы интерактивными, чтобы пользователь мог скрывать и показывать содержимое каждой группы.

Требования к интерфейсу:
- Сделать заголовки групп в панелях кликабельными.
- Каждая группа должна иметь два состояния: свёрнута и развёрнута.
- По умолчанию при создании окна, открытии проекта или первичной загрузке панели группы должны быть свёрнуты.
- При клике по заголовку группа должна переключаться между свёрнутым и развёрнутым состоянием.
- В свёрнутом состоянии должен отображаться только заголовок группы; строки/поля внутри группы должны быть скрыты.
- В развёрнутом состоянии должны отображаться все элементы группы как раньше.
- У заголовка группы должен быть понятный визуальный индикатор состояния, например стрелка/треугольник или другой стандартный маркер.
- Внешний вид должен соответствовать существующей стилистике Qt-интерфейса приложения.
- Изменение состояния группы не должно менять данные проекта и не должно запускать лишние сохранения.

Область применения:
- Реализовать поведение для групп в панелях "Свойства проекта" и "Свойства изображения".
- Если в проекте уже есть общий helper для добавления групп свойств, расширить его так, чтобы будущие группы автоматически получали поддержку сворачивания.
- Не менять структуру данных проекта, если для хранения состояния сворачивания нет отдельного требования.
- Не затрагивать меню, тулбар, канвас, список изображений и гистограммы, кроме случаев, когда это необходимо для корректной компоновки.

Требования к поведению:
- Состояние сворачивания должно быть независимым для каждой группы.
- Сворачивание одной группы не должно менять состояние других групп.
- При обновлении вычисляемых значений в скрытой группе данные должны обновляться, но сама группа должна оставаться свёрнутой.
- Если проект закрыт или изображение не выбрано, пустые состояния панелей должны работать как раньше.
- Сплиттеры и прокрутка должны корректно адаптироваться к изменению высоты групп.

Критерии приемки:
- Все группы в панелях "Свойства проекта" и "Свойства изображения" изначально свёрнуты.
- Пользователь может раскрыть любую группу кликом по её заголовку.
- Повторный клик по заголовку сворачивает группу обратно.
- Скрытие и показ группы не ломают редактирование полей и отображение вычисляемых значений.
- Обновление выбранного изображения, контура или проекта не раскрывает группы самопроизвольно.
- Интерфейс остаётся читаемым, а индикатор состояния группы ясно показывает, свёрнута она или раскрыта.
- Существующие тесты продолжают проходить; при необходимости добавлены новые тесты на сворачивание и разворачивание групп.
