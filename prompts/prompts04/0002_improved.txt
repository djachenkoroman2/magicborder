Задача: добавить в интерфейс новую панель "Свойства проекта".

Контекст:
- Сейчас в интерфейсе есть панель "Изображения проекта" и панель "Свойства изображения".
- Новую панель нужно разместить между ними.
- Панель должна отображать как настраиваемые свойства проекта, так и вычисляемые свойства.
- Структура панели должна быть расширяемой: в будущем в неё будут добавляться новые группы и свойства.
- Настраиваемые свойства проекта должны храниться в основном JSON-файле проекта.

Требования к интерфейсу:
- Добавить отдельную панель с заголовком "Свойства проекта" между панелями "Изображения проекта" и "Свойства изображения".
- Разбить свойства на группы визуально так же, как это сделано для панели "Свойства изображения", если в проекте уже есть подходящий паттерн.
- Добавить группу "Общие свойства" со свойствами:
  - "Общая информация" — настраиваемое текстовое поле, значение сохраняется в JSON проекта.
  - "Количество изображений" — вычисляемое значение, равно количеству изображений в текущем проекте.
- Добавить группу "Цветовое пространство RGB" со свойствами:
  - "Средний R" — вычисляемое значение.
  - "Средний G" — вычисляемое значение.
  - "Средний B" — вычисляемое значение.

Требования к вычислениям:
- Средние значения R, G и B должны вычисляться по пикселям внутри контуров всех изображений проекта.
- Учитывать только изображения, у которых есть корректный файл изображения и корректная аннотация контура.
- Изображения без контура, с повреждённой аннотацией, отсутствующим файлом или пустой областью внутри контура не должны ломать расчёт.
- Если нет данных для расчёта RGB, показывать пустое/нулевое состояние в стиле существующего интерфейса, например "-".
- Вычисляемые значения должны обновляться при добавлении, удалении или синхронизации изображений, изменении контура, загрузке проекта и изменении состава проекта.

Требования к данным:
- Добавить в модель проекта место для хранения настраиваемых свойств проекта.
- Поле "Общая информация" должно сохраняться в основной JSON проекта и загружаться обратно при открытии проекта.
- При открытии старых JSON-файлов без новых полей проект должен загружаться без ошибок, используя значения по умолчанию.
- Вычисляемые свойства не должны сохраняться в JSON, если в проекте уже принят такой подход для вычисляемых значений.

Критерии приемки:
- Между панелями "Изображения проекта" и "Свойства изображения" отображается панель "Свойства проекта".
- В панели есть группы "Общие свойства" и "Цветовое пространство RGB".
- "Общая информация" редактируется пользователем, сохраняется в JSON проекта и восстанавливается после повторного открытия проекта.
- "Количество изображений" корректно отражает число изображений в проекте.
- Средние R, G и B считаются по пикселям внутри всех доступных контуров проекта.
- При отсутствии подходящих контуров или файлов интерфейс не падает и показывает ожидаемое пустое состояние.
- Новая панель реализована так, чтобы добавление будущих групп и свойств не требовало переписывать всю разметку.
