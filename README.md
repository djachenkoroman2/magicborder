# MagicBorder

Локальное настольное приложение на Python и `PyQt5` для работы с фотографиями листьев растений. Приложение открывает растровые изображения, автоматически строит один замкнутый контур листа, позволяет редактировать узлы контура на канвасе и сохранять аннотацию в `json`.

## Возможности

- открытие изображений `png`, `jpg`, `jpeg`, `bmp`, `tif`, `tiff`;
- отображение изображения на канвасе;
- масштабирование: увеличить, уменьшить, показать целиком, 100%;
- SVG-иконки для всех команд меню и панели инструментов;
- автоматическое выделение контура листа;
- выравнивание фона: всё вне текущего контура становится белым;
- ручное редактирование узлов контура;
- добавление узлов двойным щелчком по сегменту;
- удаление узлов правой кнопкой мыши или клавишей `Delete`;
- сохранение изображения без отображаемого контура;
- сохранение и загрузка аннотаций в `json`.

```bash
uv sync

```

Альтернативный запуск:

```bash
uv run python -m magicborder.main
```

## Как пользоваться

1. Откройте фотографию листа через меню `Файл -> Открыть изображение`.
2. При необходимости измените масштаб через меню `Вид` или панель инструментов.
3. Запустите `Инструменты -> Определить контур`.
4. Перемещайте узлы мышью для корректировки.
5. При необходимости выполните `Инструменты -> Выровнять фон`, чтобы сделать область вне контура белой.
6. Дважды щёлкните рядом с сегментом, чтобы добавить новый узел.
7. Удалите выбранный узел клавишей `Delete` или правой кнопкой мыши по узлу.
8. Сохраните аннотацию через `Инструменты -> Сохранить аннотацию`.

## Архитектура

- `main_window.py` отвечает за главное окно, меню, панель инструментов и пользовательские команды.
- `icons.py` содержит подключение SVG-иконок, всплывающие подсказки и визуальные метаданные действий.
- `canvas.py` реализует канвас на базе `QGraphicsView`, отображение изображения, контура и редактируемых узлов.
- `detector.py` содержит алгоритм автоматического определения контура листа.
- `models.py` описывает модель аннотации и формат сериализации.
- `io_utils.py` отвечает за загрузку изображений и чтение/запись `json`.

## Примечание по алгоритму

Автоматическое выделение контура реализовано как практичный MVP: сначала используется `GrabCut`, затем при необходимости включается резервная цветовая сегментация и очистка маски. Такой подход хорошо подходит для локального настольного инструмента и оставляет пространство для дальнейшего улучшения алгоритма.
