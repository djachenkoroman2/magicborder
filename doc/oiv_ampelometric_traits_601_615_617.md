# Ампелометрические признаки OIV 601-615 и 617

Документ фиксирует ампелометрические дескрипторы OIV для зрелого листа винограда в диапазоне `OIV 601`-`OIV 615` и дополнительно `OIV 617`. Он нужен как справочник для MagicBorder: какие признаки можно измерять инструментом отрезка/расстояния, какие - инструментом угла, и как интерпретировать числовые шкалы OIV.

Основные источники:

- `OIV 2nd Edition of the OIV Descriptor list for grape varieties and Vitis species` - подробные описания, шкалы и методика измерения.
- `Resolution OIV-VITI 702-2023` - публикация 3-й редакции и актуальное подтверждение перечня кодов, включая `OIV 601`-`OIV 617`.

## Методика классификации инструментов

`Отрезок/расстояние` используется для признаков, где нужно измерить линейный размер: длину жилки, длину/ширину зубца или расстояние между двумя анатомическими точками листа.

`Угол` используется для признаков, где OIV прямо задаёт угловую величину между жилками или между жилкой и построенной касательной/линией.

`Комбинированное измерение` и `Визуальная оценка` в текущем наборе не требуются: признаки `OIV 601`-`OIV 615` и `OIV 617` являются количественными ампелометрическими измерениями зрелого листа. Все линейные признаки следует измерять в миллиметрах, угловые - в градусах. По методике OIV измерения выполняются минимум на 10 зрелых листьях из средней трети нескольких побегов; для боковых жилок, синусов и зубцов - на обеих половинах листа, если это применимо.

## Замечания по применению в MagicBorder

- Для линейных признаков достаточно инструмента `Отрезок`, если пользователь вручную ставит точки на нужные анатомические ориентиры.
- Для `OIV 607`-`OIV 610` нужен инструмент `Угол`. Для `OIV 610` предварительно требуется построить вспомогательную сторону угла: линию от черешковой точки к вершине зубца N5.
- Значения шкалы OIV являются оценочными категориями. Для промежуточных измерений желательно сохранять фактическое значение в мм/градусах и отдельно присваивать ближайший код шкалы по принятой методике проекта.
- Чтобы результаты были сопоставимы с OIV, измерения желательно усреднять по минимум 10 зрелым листьям из средней трети нескольких побегов.
- Признак `OIV 616` относится к числу зубцов между ориентирами N2 и первой вторичной жилкой N2. Он намеренно не включён как отдельный признак, потому что в задаче запрошены только `OIV 601`-`OIV 615` и `OIV 617`.
